📱 AGRI EXPERT FLUTTER APP - QUICK START GUIDE

=== PREREQUISITES ===
✓ Flutter SDK installed (https://flutter.dev)
✓ Android Studio or Xcode (for emulator/simulator)
✓ Google account (for Firebase)

=== 5-MINUTE SETUP ===

1. Install Dependencies
   cd c:\Users\anushka\Agri_Expert\mobile
   flutter pub get

2. Create Firebase Project
   - Go to https://console.firebase.google.com
   - Click "Add Project" → Name: "agri-expert"
   - Skip Analytics

3. Enable Phone Authentication
   - In Firebase Console: Authentication → Sign-in method → Phone → Enable
   - Add test phone numbers for testing

4. Connect Firebase to App (AUTO-CONFIGURE)
   flutter pub global activate flutterfire_cli
   flutterfire configure
   
   Select:
   - Project: "agri-expert"
   - Platforms: Android & iOS (or your target)

5. Run the App
   On Android:
     flutter emulators --launch <emulator_name>
     flutter run
   
   On iOS:
     open -a Simulator
     flutter run

=== TROUBLESHOOTING ===
Issue: "MissingPluginException"
Fix: flutter clean && flutter pub get && flutter run

Issue: "Firebase not initialized"
Fix: Run "flutterfire configure" again and check firebase_options.dart

Issue: "Phone number format error"
Fix: Enter 10 digits only (no country code, will auto-add +91)
