# Smart Crop Advisory System

A mobile-based application to help farmers select the most suitable crop based on soil parameters and real-time weather data, powered by Machine Learning.

## System Components
- Flutter-based mobile application
- Python (FastAPI) backend
- Machine Learning crop recommendation model
- Firebase for authentication and data storage
- Weather API (OpenWeatherMap) for real-time climate data

## Features
- User authentication (Firebase)
- Location detection and weather data collection
- Soil parameter input
- ML-based crop recommendation
- Prediction history stored in Firebase

## Tech Stack
- Frontend: Flutter
- Backend: Python + FastAPI
- ML: Random Forest / XGBoost
- Database & Auth: Firebase
- Weather Data: OpenWeatherMap API

## Getting Started
1. Clone the repository
2. Set up the backend and frontend
3. Configure Firebase and Weather API keys
4. Run the application
